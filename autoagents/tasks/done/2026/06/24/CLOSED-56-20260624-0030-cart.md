## Implementation notes
- Replaced native HTML `popover` (no anchor positioning → menu stuck at viewport top-left) with controlled dropdown in `KeyColorSelect.jsx`.
- Menu uses `fixed` positioning calculated from trigger `getBoundingClientRect()` so it works inside the cart table's `overflow-hidden` card.
- Trigger button shows color swatch + chevron only (no color name text); full label remains in `aria-label`.
- Closes on color selection, outside click, or Escape.
